# Drum Sample Assets

The bundled samples in `samples/virtuosity/` are selected single-hit assets from Virtuosity Drums by Versilian Studios and Karoryfer Samples.

Source: https://github.com/sfzinstruments/virtuosity_drums
License: Creative Commons CC0 1.0 Universal, as published in the upstream `LICENSE` file.

Only the small subset needed by the Budo `audio_drums` example is included here:

- `lofi/` uses the upstream `Samples/lofi` microphone mix, plus a close tambourine hit for the clap lane.
- `mid/` uses the upstream `Samples/mid` microphone mix, plus a mid tambourine hit for the clap lane.
- `oh/` uses the upstream overhead microphone mix.
- `room/` uses the upstream room microphone mix.
- `kick/` uses the upstream kick microphone mix.
- `snare/` uses the upstream snare microphone mix.

The clap lane uses a tambourine shake from `Samples/perc/mid/tambourine` for the added kits because the source drum library does not include handclap samples.
