# Native C canvas example

Native C code is trusted and unsandboxed. Only compile and package source you
trust. This core canvas starter is also generated by `budo init my-native-app
--language c`.

This application implements `budo_get_application()` and lifecycle callbacks
without defining the process `main()` function. It demonstrates
application-owned state, host logging, frame timing, resize handling,
pointer/touch and arrow-key input, core canvas drawing, and paint recreation
across graphics context loss.

`budo-native.json` declares the constrained native project model. Build and run
it with `budo compile examples/12_native_c --run`; the generated build links
the application through `budo::native_launcher`.

For source-level debugging or Clang/GCC application-code sanitizers:

	budo compile examples/12_native_c --debug
	budo compile examples/12_native_c --debug --sanitize address,undefined

Package the same source for Android with Budo Pro:

	budo android-apk examples/12_native_c
